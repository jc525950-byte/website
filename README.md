# SkySales 软件官网

基于 React 与 Ant Design 构建的 SkySales 软件销售官网首页，提供响应式布局、SEO 友好的语义结构以及首页核心模块。

## 特性

- ⚛️ 使用 React + Vite 构建，开发体验轻量快捷
- 💠 集成 Ant Design 组件库与自定义主题
- 📱 通过媒体查询与栅格系统适配桌面与移动设备
- 🔍 在 `index.html` 中设置 SEO 相关的 `meta` 标签
- 🧩 首页包含导航、英雄区、产品特性、行业方案、价格套餐、客户口碑、CTA 以及页脚模块

## 开发

```bash
npm install
npm run dev
```

访问 <http://localhost:5173> 查看开发环境页面。

## 构建

```bash
npm run build
```

打包产物将输出至 `dist/` 目录，可使用 `npm run preview` 在本地预览。
